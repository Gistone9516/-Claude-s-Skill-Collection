# work-panel 설계서 (1차)

규칙: P-1~P-17 (17건), 검증: V-1~V-6 (6건)

Claude Code CLI 옆에 붙는 작업 현황판이다. 작업 중 상태(진행, 계획, 규칙, 포트폴리오 제안과 후보)를 패널에 모아 두고, 채팅에는 결정이 필요한 것과 결론만 남긴다. 사용자 요청 2026-10-12: "패널에 띄워준다면 앞으로 내게 띄우는 메인 출력 컨텍스트를 최소화할 수 있겠지."

이 문서가 동작 규칙의 단일 출처다. 코드와 이 문서가 다르면 둘 중 하나를 고친 뒤 같은 커밋에 넣는다.

## 1. 어디에 그려지는가

사용자의 화면 구성(2026-10-12): 왼쪽은 VS Code 확장을 주 작업 창으로, 오른쪽은 CLI를 사이드 패널로 쓴다. "cli는 반응이 한 템포 느리기도 하고, UI 작업할 땐 vscode가 편하거든."

- **작업 세션 (주로 VS Code)**: 2.1.296의 확장은 mod 화면을 그리지 않는다(측정 2026-10-12, anthropics/claude-code#99045). 훅은 돌기 때문에 상태를 모아 `$.store`의 자기 세션 칸에 올린다.
- **현황판 세션 (CLI)**: `$.store`를 읽어 가장 최근에 움직인 다른 세션을 Pane에 그린다. 버튼과 입력칸은 여기에 있다.
- mod는 세션마다 따로 돈다. 두 세션을 잇는 것은 이 컴퓨터의 모든 세션이 함께 쓰는 `$.store`뿐이다.
- 로드는 `~/.claude/settings.json`의 `env.CLAUDE_CODE_PLUGIN_DIRS`에 이 폴더를 넣어 두 환경의 모든 세션에서 한다. 같은 mod가 그릴 화면이 있으면 현황판으로, 없으면 작업 세션으로 동작한다.

## 2. 계층 구조

```
hooks/register.tsx     등록만 한다. 이벤트를 받아 수집기에 넘기고, 그리기를 화면 조각에 넘긴다
src/collect/           수집기. 이벤트를 상태 변경으로 바꾸는 순수 함수 (스킬, 규칙, 에러, 저장소, 할 일)
src/state.ts           상태의 유일한 정의. $.state 원자와 $.store 키를 여기서만 만든다
src/view/              화면 조각. 상태를 받아 트리만 그린다. 상태를 바꾸지 않는다
src/sources/           바깥 읽기의 유일한 위치 ($.fs, $.process). 수집기는 이것을 통해서만 밖을 본다
types/index.d.ts       PluginState 계약
```

수집기가 순수 함수라 엔진 없이 단위 시험한다. 화면이 상태만 읽기 때문에 같은 판정이 탭마다 따로 구현되지 않는다.

| P-16 | 칸마다 쓰는 쪽은 하나다. 진행 메모, 요청, 계획, 읽은 스킬, 제안은 그 세션이 자기 세션 칸에만 쓴다. 뺀 제안의 목록(`$.store`의 `viewer:dismissed`)과 `candidates.json`은 현황판 세션만 쓴다. | 사용자 2026-10-12 (두 환경을 함께 씀) | 여러 세션이 한 칸을 읽고 고치고 쓰면 나중에 쓴 쪽이 앞의 변경을 지운다. 쓰는 쪽을 하나로 두면 그 경합이 생길 수 없다(DG-3) | `pending suggestions skip picked and dismissed` |
| P-17 | 현황판 세션은 몇 초마다 `viewer` 키에 살아 있다는 시각을 남긴다. `panel_post`의 응답은 현황판이 켜져 있는지(최근 15초 이내 표시가 있는지)를 함께 돌려준다. 켜져 있으면 Claude는 진행 보고를 패널에만 하고 채팅은 결정과 결론만 쓰며, 패널에 올린 것을 채팅에서 다시 정리하지 않는다. 꺼져 있으면 채팅에 보고한다. 응답은 켜짐과 꺼짐만 짧게 알린다. 규칙은 도구 설명에 있어 호출마다 되풀이하면 컨텍스트만 쓴다. | 사용자 2026-10-12: "현재 환경에 cli가 켜져있는지 확인 절차". 스킬이 아니라 도구 응답에 둔 이유: 스킬은 필요한 순간에 읽히는 비율이 19~43%였다(측정 2026-10-12) | 판단에 필요한 사실이 행동하는 바로 그 순간에 도착해야 한다 | `post reports viewer state` |
| P-14 | 비밀값은 그리기 전에 가린다. 가림 규칙은 `plog.py`의 PL-7과 같은 목록을 쓴다. | portfolio-log PL-7, 측정 2026-10-12 (웹훅 주소 노출) | 패널은 화면 공유나 스크린샷에 그대로 찍힌다 | `masks secrets` |

## 7. 화면 우선순위와 크기

세션 탭의 메모는 자르지 않고 줄바꿈해 전부 보인다(사용자 2026-10-13: "한 눈에 파악하기 위함인데 … 중요한 내용은 전체 출력"). 칸마다 최근 6건까지 보이고 나머지는 "이전 N건 더 있음"으로 센다. 패널은 60줄로 열고 최소 높이를 주며, 넘치는 내용은 엔진이 스크롤한다. 이미 열린 패널은 크기 요청이 먹지 않으므로 `/panel`은 닫았다가 다시 연다.
